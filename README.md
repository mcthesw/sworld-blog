# Sworld's World

个人站点：[blog.sworld.club](https://blog.sworld.club)，以思源笔记为写作源，基于 Quartz 5 构建。

```sh
pnpm install --frozen-lockfile
pnpm dev      # 本地预览 http://localhost:43781（热更新 43782）
pnpm check    # 类型检查与回归测试
pnpm build    # 构建静态产物至 public/
```
