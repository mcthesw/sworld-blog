### 类型偏好

我想要尽可能多地体验各种类型的游戏！

#### 最爱的几款游戏

- 以撒的结合：最伟大的roguelike游戏！
- 博德之门：我愿称之为现代游戏工业的奇迹，神界原罪2也很推荐。
- 黑魂3、法环、只狼
- 星际拓荒：我很难形容它，非常浪漫的一款游戏。
- 塞尔达传说系列
- 怪物猎人系列
- 帝国时代系列

#### 近期比较喜欢的作品

- Z.A.T.O. // 我爱这个世界及其中的一切！
- 动物井
- Slay the princess：你正走在一条林间小路上，小路的尽头有一座小屋。小屋的地下室里有一位公主。你是来送她上路的。如果你失败了，世界就会走向终结。
- 毁灭战士黑暗纪元：弹反，爽！
- 终之空
- 边缘世界
- 空之轨迹 the 1st
- 天国：拯救2
- 近月少女的礼仪系列，尤其是少女理论及其周边
