最近 bilibili 总是给我推荐《近月》的视频切片，让我又回想起了当时玩「近月」时的感受，但是我不想再反复重温这个我恨喜欢的作品了，在看到 [Asuka Minato](https://github.com/asukaminato0721) 的头像和名字时，我出于好奇搜索到了出处「少女 * 领域」，感觉很有趣，于是果断入手并当天推完了风莉线。

## 初印象

![封面](cover.png)

游戏的开局还是挺有戏剧性的，主角飞鸟凑在最后一个熟悉的亲人逝世的葬礼上，被大小姐风莉邀请入学并提供基本生活、学费的帮助，而在后续第一天入学时，才向玩家揭示了这是一座女校的事实，凑为了能够继续接受风莉的帮助（并完成亲人的遗愿），决定女装潜入这所女校，开始了他的校园生活。刚入住寝室，凑和风莉住在一起，于是有了关于宝特瓶的开幕雷击剧情，这段让我有点想起了「樱花庄的宠物女孩」。

主要角色的介绍在steam页面上已经挺完善了，这里就不赘述了，对我来说所有角色的印象都是挺好的，整个故事中没有出现让我讨厌的角色，没有让人胃疼的剧情安排，总体上是甜蜜加小小的波折，适合让人放松。

另外，据说steam版本由于删减了R18内容，导致直接无法进入风莉线，我没有亲自尝试过，如果真是这样，我推荐任何人游玩前先打上补丁。

## 游戏的程序

可能因为游戏有一些年头了，程序自带的缩放功能在4K显示器上观感比较差，我使用[Magpie](https://github.com/Blinue/Magpie)与Anime4K的组合将游戏缩放到了4K，这样画面感觉就很不错了，没有因为缩放算法严重破坏游戏本身的风格，唯一的问题是这一套和steam的覆盖、截图功能不太兼容，例如截图变成了这样：
![alt text](202604~1.JPG)

还有一个问题是经常会报错“无法为位图分配内存”，好在弹窗出现后如果选择yes程序会自动重启，并定位到上次对话进行到的位置，基本上不会对游玩造成太大影响。
