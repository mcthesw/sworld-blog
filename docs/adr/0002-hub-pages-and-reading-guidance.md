# 聚合页采用页内查询与精选导读，不向图谱注入查询出链

站点取消强制分类目录后，如果让「时间线」「游戏」等聚合页把动态查询结果作为出链注入图谱，每篇笔记的反向链接都会出现聚合页，全局图谱也会退化为以聚合页为中心的放射状结构，掩盖笔记之间的真实关联；但若只提供单一时间线，深度技术长文又容易被高频短篇（如游戏 Demo 记录）冲出首屏。

我们决定让聚合页继续使用页内 `base` 代码块渲染列表与卡片（仅构成「查询收录」，不写入图谱出链），并通过思源 `custom-featured=true` 属性驱动首页与时间线顶部的「精选」区域引导深度阅读。只有作者在正文中显式书写的站内链接才进入双链与局部图谱；无正文出链的纯聚合页隐藏右侧空图谱与空反向链接。
