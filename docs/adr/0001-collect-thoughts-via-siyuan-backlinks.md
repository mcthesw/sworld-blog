# 以思源反向链接块采集「随记」而非公开整篇日记或使用标签

即兴的作品短评与一句话感想大多在思源 `/daily note/` 日记中随手写下。整篇日记包含私人生活记录，按站点隐私边界禁止直接公开导出；但如果要求每次写一句话感想都切换到专门的文档，会打断日常记录心流，而使用 `#标签#` 又与本站不依赖标签的组织方式冲突。

我们决定在思源中以一篇公开文档（设置 `custom-backlinks=true`，对应站内「随记」页）作为采集锚点。同步脚本通过思源 `refs` 表查找所有指向该文档的反向链接块：若引用发生在列表项或引述块内，则以该列表项或引述块为一条完整随记；否则以所在段落为一条随记。导出时自动剥离指向「随记」文档自身的标记链接，并复用现有的引用改写与图片压缩管线，而日记中的其他段落完全不读取、不导出。
