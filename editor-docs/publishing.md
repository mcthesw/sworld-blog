# 思源写作与本地导出

## 桌面插件

插件源文件在 `siyuan-plugin/`，调用 `scripts/publish-desktop.mjs`，复用同一套思源转换逻辑。支持 Windows 桌面版思源 3.8.9+，不支持浏览器、手机或远程内核。需要 Node、已安装依赖的本站仓库及可用的 `siyuan` CLI。

在仓库执行 `node scripts/install-siyuan-plugin.mjs`，通过本机思源内核安装到 `/data/plugins/sworld-publisher/`；非默认内核端口使用 `--url http://127.0.0.1:<端口>`。安装不更改文章公开状态。在思源「设置 → 集市 → 已下载 → 插件」启用「网站导出」，点击顶栏上传图标进入。

1. **本地连接设置**：填写仓库目录、Node 可执行文件和隔离预览目录。预览目录必须与仓库、思源工作区相互独立，默认 `D:/Coding/temp/sworld-publisher`。工作区取自当前思源窗口，并与 CLI 校验，不默用其他工作区。
2. **当前文章**：打开面板时通过 `getActiveEditor()` 捕获当前根文档。公开开关立即保存 `custom-publish`，关闭时确认撤回；不会导出或上线。首次允许公开的新笔记记录 `custom-date`，已有日期不变。没有当前文章或位于禁止导出的 daily note 时禁用开关和当前预览。
3. **预览当前文章**：无需勾选，不修改公开许可；构建完成后自动打开当前文章，多篇预览打开笔记列表。已公开文章与当前文章共同构成隔离快照，不带入其他旧博客文章；只显示预览就绪状态，不展示可能误解为正式撤回的差异清单。
4. **检查待导出内容**：按全部已保存的公开许可生成快照、转换图片并构建，日常更新无需重选。结果区显示新增、更新、撤回摘要及可滚动明细；未公开的旧博客文章也会列为撤回。没有公开文章时禁用检查，不生成空批次。
5. **导出到本地**：再次确认后才把已检查快照写入仓库 `content/`。未公开预览不可用于正式导出；公开列表、网站内容或快照文件变化后必须重新检查。

空公开列表或没有思源文章的快照不能正式导出；桌面插件不执行 Git 提交、推送或部署。预览服务仅监听 `127.0.0.1`，下一次检查或停用插件时关闭。

## 网站图片

- 只转换导出副本，不修改或新增思源原图资源。正文、附件图片与原生题头图复用同一处理逻辑。
- 本地 PNG、JPEG、GIF、AVIF、TIFF 等位图转为 WebP；宽度上限 2560 像素、不放大，质量 85，保留透明度和 GIF 动画。静态图片按 EXIF 方向旋转，输出不携带 EXIF、XMP 或 ICC 元数据。
- 合适尺寸且无上述元数据的现有 WebP 直接复用，不重复有损压缩；输出名称带原文件内容哈希，原图改变时资源 URL 随之改变。
- SVG 保留矢量格式，非图片附件保留原格式。APNG 暂不支持，会阻止导出，不能静默只保留首帧。
- HTTP(S) 外链图片不自动下载，保留原地址并给出提示；需要压缩时先将图片保存为思源资源。

## 内容与发布关系

- 正文在思源编辑；`content/` 中的思源输出不手工修改。
- 文档所在位置、标签与公开状态独立。只有 `custom-publish=true` 才进入全量同步。
- 旧文章接管时设置 `custom-permalink` 为原 URL、`custom-date` 为原发布日期，保留原文档标题。现有 Giscus 使用 `og:title` 匹配旧讨论。
- `custom-date` 支持带时区的 ISO 时间、旧博客的 `YYYY/MM/DD HH:mm:ss` 和思源的 `YYYYMMDDHHmmss`。显式时区原样保留，无时区的后两种格式按北京时间处理。
- 页面日期使用发布日期；思源修改时间保存在 `updated` 中，不替代原发布日期。
- 双链和时间线是主要组织方式，不要求分类或标签。同步不导出思源标签和普通备注，摘要仅使用显式的 `custom-description`。
- `custom-featured=true` 导出为 `featured: true`，用于首页与时间线的「精选」展示。
- `custom-backlinks=true` 用于「随记」类聚合文档：同步器通过思源 `refs` 表提取指向该文档的反向链接块（若位于列表项或引述块内则提取整个列表项或引述块），剥离指向该文档自身的标记链接后按日期倒序拼接（日期取所在日记的日期，非日记则取块创建日期；同日多条合并在同一日期标题下），不读取或导出引用来源文档（如 `/daily note/`）的其余正文。
- 网站封面直接读取思源原生题头图 `title-img`，无需额外填写封面属性，也无需在正文重复插入该图。原生题头图属于思源资源引用。
- 图片型题头图中的 `assets/` 文件随文章转换导出，HTTP(S) 图片保留原地址并提示。没有题头图、纯色或渐变题头图使用标题卡片，不复刻题头图的裁剪位置。题头图仍指向已删除的本地资源时阻止本轮导出，不自动补传；如不再使用封面，应在思源取消题头图。
- 旧 VuePress 的视频标记可转成普通链接；图片说明可转成标准 Markdown 图片与说明文字，不要求保留复杂排版。
- 接管后的正文以思源为准，不再用旧博客覆盖；已有原稿只补迁移属性，不重复导入。空稿不因迁入「已产出」而获得公开许可。
- 思源 Markdown 导入可能将外部 `.md` 链接转成 Wiki 链接，导入后须核对原 URL；图片须逐个核对实际资源路径与文件哈希，不能仅凭导入成功判断资源完整。

## 双链与私人引用

- 思源块引用（静态文字、动态文字、无文字引用）及 Markdown 思源链接会转换为网站链接。块级引用目前定位到所属文档，不定位到具体段落。
- 目标在本轮导出集合内时，保留引用文字并链接到目标文档；Quartz 据此生成反向链接。
- 私人、缺失或禁止公开的目标保留原引用文字，统一链接到 `not-public`。标题和引用文字允许公开，但不读取或导出私人正文，也不把私人 ID 放进链接。
- 无引用文字时，公开目标使用其标题，其他目标显示「不公开页面」。不额外查询私人标题。
- 统一提示页可直接访问，但标为 `unlisted`，不进入搜索、RSS、时间线或图谱，也不展示反向链接。
- 嵌入块仍移除。HTML 或引用式 Markdown 等未支持的思源链接会阻止本篇导出，需改为普通块引用或 Markdown 思源链接；代码示例保持原样。
- 公开文档的普通正文、标题、手写引用文字和显式摘要本身属于公开内容，发布前仍应自行检查。撤回时清理思源输出的文章及其目录内不再被剩余页面引用的资源，不代表已撤销 Git 历史、外部缓存或读者下载。

## 当前导出边界

- 整批转换、路径冲突检查及资源读取完成后才开始写入。缺失正文图片、附件或题头图会报错退出；这些检查失败时不修改既有输出，`--dry-run` 执行相同检查。
- 文档 URL 必须位于内容目录内；重复 URL、文章资源目录重名，以及覆盖非旧博客／非同一思源文档的页面均被拒绝。
- 更新文章时清理该文章资源目录内不再引用的文件；全量撤回时一并检查被撤回文章的资源目录。其他剩余页面的 Markdown 图片／链接、引用式链接、HTML `src`／`href` 和封面仍使用的文件会保留；不扫描清理其他资源目录。被其他页面保留的资源，日后删除最后一处引用时可能仍需手动清理。
- 代码中的图片示例不会当成待导出资源。普通 Markdown 图片、附件链接及引用式链接会转换资源路径；HTML 中的本地资源需先改成 Markdown 链接。
- 磁盘或操作系统写入故障仍可能留下不完整的本地输出，不保证回滚。发生写入错误后不要提交或部署，应先修复并重新导出。
- 本地生成文件、内容允许公开、线上部署成功是不同状态；当前导出脚本不执行部署。

## 未公开文档的隔离预览

`--id` 会显式导出指定文档，即使它没有公开标记；它不是只读计划。脚本把内容写到**当前工作目录**下的 `content/`，同路径文件会被覆盖。

使用独立的临时目录验证，避免将未公开文档写入正式内容目录。以下为 PowerShell 示例：

```powershell
$repo = (Get-Location).Path
$preview = Join-Path 'D:/Coding/temp' ('sworld-preview-' + [guid]::NewGuid())
New-Item -ItemType Directory -Path $preview | Out-Null
Copy-Item (Join-Path $repo 'content') (Join-Path $preview 'content') -Recurse

Push-Location $preview
node "$repo/scripts/sync-siyuan.mjs" --id <思源文档ID>
Pop-Location

node quartz/bootstrap-cli.mjs build -d "$preview/content" -o "$preview/public" --concurrency 1
```

- `--dry-run` 只打印计划，但仍会读取思源和转换内容，不写输出。
- `--id` 可重复指定，多个指定文档组成一次预览集合；集合内引用正常互链，集合外引用进入统一提示页。可以用两个未公开文档验证双链，无须更改思源公开标记。
- `--attr` 临时覆盖会应用于本轮所有指定文档，不写回思源。不要给多个文档覆盖同一个 `custom-permalink`。
- 指定 `--id` 时不清理其他文档，只更新所选文章及其资源；全量同步会移除取消公开的 `source: siyuan` 输出及无人引用的所属资源，并将其他文章对它的引用改为统一提示页。
- 预览构建不等于部署，不要提交临时输出。不要把旧博客导入和思源同步交替覆盖到同一正式目录。

## 评论检查

评论按 `og:title` 匹配 `mcthesw/sworld-blog` 的 GitHub Discussions，预览也会连接真实讨论。查看旧评论无需发布文章；提交评论或回复会公开写入 GitHub，不是隔离测试。

可用 `/2026/02/8d28e545`（华硕ProArt MD301使用体验，对应 Discussion #28）检查旧评论是否显示。不要为测试提交无意义评论。
